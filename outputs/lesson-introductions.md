## 第一关：让 Agent 理解任务

### 本关学什么

学会把自己的想法说清楚，让 Agent 知道要完成什么，以及结果需要满足哪些要求。

### 先理解这些概念

Agent 是一种能够围绕任务使用模型和工具开展工作的助手。它可以帮助整理资料、查找信息、生成文件，但需要你说明目标，并检查它的结果。

你发给 Agent 的任务说明，通常叫作“提示词”。提示词可以用普通话语表达，不需要写代码。“目标”是你希望得到什么，“约束”是完成任务时需要遵守的要求，例如只使用提供的资料，或按指定格式输出。

Agent 不一定知道你心里省略的信息。说明越具体，通常越容易得到符合要求的结果；不过，清楚的说明也不能保证结果完全正确。

### 看一个小例子

“帮我看看这段通知”没有说明需要怎样的结果。可以改成：“请从这段通知中提取需要办理的事项和截止时间，整理成清单；未说明时间的事项请标注‘未说明’，不要自行猜测。”

### 接下来做什么

阅读提供的短通知，先用一句简单要求让 Agent 尝试，再补充目标、限制和输出要求，比较两次结果。

### 做到什么算完成

- 完成两次真实尝试，并能指出任务说明的变化。
- 检查结果是否更接近自己的要求。
- 完成本关的简短理解题。

## 第二关：给 Agent 足够的资料

### 本关学什么

学会为 Agent 提供与任务有关的资料，并检查回答是否有依据。

### 先理解这些概念

“上下文”是 Agent 在处理当前任务时能够参考的信息，例如你发出的消息、之前的对话，以及工具读取后返回的资料。

文件放在电脑上，并不代表 Agent 已经知道其中的内容。你需要把资料放入本关工作区、选为任务材料，并确认 Agent 实际读取了它。文件名只能告诉它资料可能是什么，不能代替文件正文。

“信息来源”是回答所依据的材料。检查来源，可以帮助你区分哪些内容来自通知，哪些是 Agent 的补充或猜测。资料没有说明的信息，应让它标记缺失或向你询问。

### 看一个小例子

询问“这周有哪些作业”时，Agent 可能缺少你所在课程的信息。提供本周通知并要求“根据这些通知整理，同时标注来源”，结果就更容易核查。

### 接下来做什么

选择本关提供的课程通知，让 Agent 读取资料并整理指定信息。查看读取记录，再将回答与原文逐项对照。

### 做到什么算完成

- 能在运行记录中找到必要材料的成功读取结果。
- 整理结果包含任务要求的信息，并能对应到材料来源。
- 对资料缺失的内容作出说明，没有把猜测当作已知事实。

## 第三关：让 Agent 使用工具

### 本关学什么

认识工具调用，学会确认 Agent 是否真正获取了完成任务所需的信息。

### 先理解这些概念

“工具”是提供给 Agent 的一项具体能力，例如读取文件或查询课程安排。模型可以提出使用某个工具，由程序执行后把结果返回，Agent 再根据结果继续完成任务。

“工具输入”是执行时需要的信息，例如要查询哪门课程；“工具结果”是执行后得到的信息，例如课程日期与地点。工具调用可能成功，也可能因为输入不完整或服务异常而失败。

Agent 在回答里说“我已经查到了”，不等于查询确实发生。本关会让你查看实际调用记录，了解工具执行与最终回答之间的联系。

### 看一个小例子

整理课程待办时，如果需要确认某次课程的安排，可以让 Agent 使用课程查询工具，并根据返回日期调整清单。若查询失败，应先解决问题或说明信息缺失。

### 接下来做什么

本关已经提供课程安排查询工具。让 Agent 查询任务指定的信息，检查它传入了什么、得到了什么，再观察这些信息如何进入待办草稿。

### 做到什么算完成

- 完成指定的真实工具调用，并查看返回结果。
- 待办草稿正确使用了查询到的信息。
- 能区分任务说明、工具执行结果和 Agent 的最终回答。

## 第四关：管理权限并检查成果

### 本关学什么

学会在 Agent 执行操作前进行确认，并检查生成的文件是否满足任务要求。

### 先理解这些概念

“权限”规定 Agent 可以进行哪些操作。本关中，读取课程材料和保存待办文件具有不同的操作要求；保存前需要你批准。

“授权”是你对一次具体操作作出的决定。你应先检查准备保存的内容和位置，再选择批准或拒绝。拒绝表示这次保存不能执行；批准一次也不代表之后所有操作都获得许可。

“产物”是任务实际生成的结果，例如一份待办清单文件。Agent 回复“已完成”后，仍应打开文件检查内容。成功保存说明操作执行了，但清单是否完整、日期是否正确，还需要结合资料核验。

### 看一个小例子

Agent 准备保存一份待办清单，你发现其中漏了一项任务。可以先拒绝保存，让它补充，再检查新的保存请求。确认后批准，并打开生成的文件查看。

### 接下来做什么

检查 Agent 提出的待办清单保存请求，先练习拒绝并观察文件未发生变化，再要求重新保存、核对内容并批准。最后打开产物，与原始通知和查询结果对照后提交。

### 做到什么算完成

- 拒绝一次保存，确认该操作没有改变文件。
- 核对新的保存请求并批准，成功生成清单文件。
- 检查必要事项、日期和来源，提交产物并阅读反馈。
