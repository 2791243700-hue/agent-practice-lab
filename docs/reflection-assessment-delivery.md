## 当前行为

- 首页读取现有模型配置状态，有任意 credential_status=configured 时隐藏“准备好你的第一把钥匙”；全部凭据缺失后恢复。状态未确认时不闪现提示，返回页面/窗口会刷新，不因状态查询失败阻断课程浏览。隐藏准备提示不代表连接检查已通过。
- 第一关移除旧二选一题和旧提交入口，以四步复盘作为新的验收模板：选择两轮、标出改动、核对回答、换个情境。
- 只选择当前实训、相同模式、已完成且有完整回答的运行；第二轮必须在之后且指令不同。引用与原指令/完整回答核对并标亮，允许指出第二次仍有问题。
- 小变式用虚构活动通知区分已知与待确认信息，不调用模型。系统仅核对引用和信息判断，不对解释或改写质量评分。
- 可下载带 Run/事件引用的 Markdown。修改草稿后需重新整理；草稿只在页面内存中，刷新/离开后清空，不写浏览器持久存储、不发送新提交、不包含在原有 ZIP 导出中。
- 第一关标注为预览，当前无法通过此界面新生成正式通关成绩。旧成绩保留，反馈明确标为原版本历史结果，不能用新复盘替换旧证据。
- 第二关保留读取、日期与来源校验；第三关保留真实查询与课程信息核对；第四关保留审批、实际保存与产物内容验收。它们继续以服务端 Submission.passed 决定正式通过。

## 启动与复核

仓库根目录执行：

```powershell
uv sync --project apps/api --locked
npm --prefix apps/web ci
.\scripts\start.ps1
# http://127.0.0.1:3000
# 停止：.\scripts\stop.ps1
```

第一关完成两轮对话后，在验收区选择两轮，引用新增要求和两次回答、写出判断，再完成活动通知练习并下载复盘。全程不会自动提交正式成绩或替学生选择旧题答案。无需真实 Key 的界面核对可用显式演示模式，但演示不计正式通过。
