# 当前版本与文档索引

更新：2026-10-27。本版本加入正式模型内容验收及实训缺失项定位，开发基线为 main `0b15af9`（PR #14）。接口、界面和课件随同一 PR 交付；合并状态及云端检查以该 PR 的 Checks 为准。

## 当前范围

- 四关文字导读、版本化实验、统一教学 Agent、模型与内存 Key 管理、工具授权、产物预览和学习记录导出。
- 第一关最新 **1.2.0**，第二至四关最新 **1.1.0**：正式通过需要所有客观必要项及所有模型内容项通过。旧实验和旧成绩按原版本保留，不自动升级或重算。
- 提交前展示本版评分标准、所选模型、发送范围与费用同意。第二至四关补充自己的核对说明；第一关沿用四步复盘。客观检查未通过不调用验收模型；超时、无效结果或服务不可用时冻结未完成提交，不放行、不自动重试。
- 复盘草稿后端自动保存；正式提交冻结答案、模型报告与文件快照，历史和 ZIP 可回看。模型 Tips 独立、按需生成，不影响正式成绩。
- 模型设置页提供 DeepSeek 申领入口，当前连接通过检查后隐藏，失效后恢复。首页准备提示仍按是否存在已配置 Key 判断，两者不混用。
- 导读与主任务区域对齐，左侧任务设置可收起；问题立即显示、回答逐段跟随。支持 Ctrl+Enter 发送和首次使用提示，Enter 换行。
- 点击“下一步”或“提交验收”时列出缺失项、标记字段并定位第一处问题；补齐后标记自动消失，未完成时不发送验收请求。
- 契约 v0.1.0 为 **41 个 HTTP 操作、109 个 schema、11 类 SSE 事件**。本次为原 `/submissions` 的兼容扩展，无新增路径或 SSE 类型，前端类型由 OpenAPI 生成。

## 验证与边界

2026-10-27 本地验证：后端 242 项、前端单元 19 项、完整浏览器 70 项、契约结构 244 项通过；类型、格式、Ruff、隔离生产构建及文档链接检查通过。新评分覆盖模型拒绝、无效/伪造引用、网络失败、付费幂等、并发互斥、回滚、四关真实工具路径及历史兼容。详见[模型验收交付](model-assessment-2026-10-27.md)和[缺失项反馈](form-validation-2026-10-27.md)。本地结果与云端 CI 分开记录。

1. 新验收使用脚本模型和 MockTransport 自动化验证，未新增外部模型判断质量或零经验学生独立验收记录。模型可能误判，应结合反馈引用核对；不宣称任意模型都能可靠识别所有敷衍答案。
2. Key 只存后端内存，服务重启需重新输入；关卡重置保留 Key、模型和连接检查。浏览器不存 Key，内部令牌只由同源服务端代理转发。
3. 第二至四关未提交的核对说明仅存当前页面，刷新前需自行备份；已返回的验收提交可从历史恢复查看。第一关使用服务端复盘草稿。
4. 结果不明确的付费请求不能用相同幂等键重发。先检查历史；确认后主动重新提交可能再次计费。超长正式证据拒绝调用，不静默截断。
5. 第四关 task_id 指导、启动器前端 HTTP 就绪等待仍待完善。登录、班级、线上部署、任意代码执行、文件上传和多用户调度未实现。
