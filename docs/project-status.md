- 第一关 1.3.0 必做为“两轮对话＋一句复盘”：系统带入最近两轮完整对话，可更换；学生只需选择结果判断并说明依据，不再手工摘录。小变式为选做自查，不进入正式评分。学生未另附通知时，“这段通知”默认指本关固定材料。

- 四关均支持服务端草稿。第二至四关可恢复填到一半的核对表，重开页面后须重新勾选验收费用同意。正式提交冻结当时的答案和文件快照。
- 同一浏览器按实训记住主动选择的模型，原连接失效时提示重选。模型设置区分待检查、失败和未执行。

- 点击“下一步”或“提交验收”时列出缺失项、标记字段并定位第一处问题；补齐后标记自动消失，未完成时不发送验收请求。
- 某轮历史读取失败可单独重试。学习记录展示课程版本、已完成轮数和最近任务，导出 ZIP 按轮次收录任务、回答和已保存的 Tips。旧版导读可跳转当前版本。

## 验证与边界

2026-11-21 本地验证覆盖 273 项后端测试、22 项前端单元测试、82 项浏览器测试和 261 项契约结构检查。浏览器使用本地脚本模型，覆盖四关 Tips、关闭后续学、跨标签页冲突、模型失效和单轮重试。

1. 新验收使用脚本模型和 MockTransport 自动化验证，未新增外部模型判断质量或零经验学生独立验收记录。模型可能误判，应结合反馈引用核对；不宣称任意模型都能可靠识别所有敷衍答案。
2. Key 只存后端内存，服务重启需重新输入；关卡重置保留 Key、模型和连接检查。浏览器不存 Key，内部令牌只由同源服务端代理转发。
3. 服务端恢复最近一次保存成功的草稿。保存冲突时可下载本页填写并重读服务端版本。
4. 结果不明确的付费请求不能用相同幂等键重发。先检查历史；确认后主动重新提交可能再次计费。超长正式证据拒绝调用，不静默截断。
5. 第四关 task_id 指导、启动器前端 HTTP 就绪等待仍待完善。登录、班级、线上部署、任意代码执行、文件上传和多用户调度未实现。
