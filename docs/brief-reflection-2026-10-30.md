# 第一关精简验收

第一关 1.3.0 将必做流程改为：第一次尝试 → 补充要求再试一次 → 选择结果判断并写一句依据 → 提交验收。

系统为没有已选轮次的草稿带入最近两轮完整对话；学生可以更换。已有选定轮次和填写不因新对话或刷新而被覆盖。完整指令和回答自动作为评分依据，不再要求复制原文、填写引用位置、分类新增要求或另外填写下一步指令。评分只检查新增要求是否有效、结果判断是否有依据；准确指出回答不足也可以通过。

活动通知小变式放在独立折叠区，提供公开自查提示，不调用模型、不决定通关。未填、部分填写或答错都不会阻挡必做验收；选做内容随草稿保存，但不发送给正式评分模型。原“开始时间”改为“集合时间”，避免混淆集合与活动开始。

教学 Agent 收到明确的默认材料指引：学生未另附通知时，“这段通知”默认指本关固定参考通知，不再要求重复粘贴；学生明确提供或指定其他通知时优先使用该材料，缺少的事实仍需确认。

## 兼容与证据

- 新版使用 `brief_reflection` 表单及答案，复用已有草稿接口；原 1.0.0—1.2.0 包不改动，既有实验与成绩不重算。
- 后端核对同实验、同模式、真实顺序、已完成状态、非空助手完整消息及完成事件。仅所选两轮进入模型评分，仍执行逐字引用校验、付费幂等、冻结结果、无效评分拒绝和费用同意。
- 运行列表提供 `creation_index`，前端使用真实创建顺序而非电脑时钟排序。独立审查发现的时间回拨问题已修复，并补充相同时间戳和回拨测试。
- 评分标准 1.1.0 只有两个必过内容项。旧版评分标准及小变式证据修复保留。
- 契约现为 41 个 HTTP 操作、111 个 schema、11 类 SSE 事件。前端类型由 OpenAPI 生成。
- 使用最新导读新建实训才能体验简版；“重置环境”仍创建同版本实验。

## 验证

自动化使用隔离数据库、虚构凭据、MockTransport 或本机脚本模型，不使用真实 Key 或外部付费模型。后端回归覆盖有效简版提交、非满意判断仍可合格、选做不影响评分、草稿恢复，以及同轮、反序、跨实验、失败运行、空回答、非助手消息、缺终态与空解释被拒绝。浏览器覆盖桌面和手机的默认轮次、刷新恢复、拒绝后修改与选做不阻挡提交。

构建验证可设置 `AGENT_SCHOOL_NEXT_DIST_DIR=.next/brief-validation`，避免影响运行中的开发页面；启动对应测试服务时需设置相同值。最终执行结果记录在实施计划中。

## Tips 兼容修复与接口同步

第二关 facts 表单只有 tasks/sources，没有 prompt。此前 Tips 整理上下文时直接读取 prompt，导致调用模型前抛 KeyError 并返回 INTERNAL_ERROR。现在仅读取实际存在的公开字段，并带入 facts 的任务与来源。七个课程版本、五种表单的模拟服务回归均通过；本次未调用外部付费模型。Tips HTTP 契约与缓存语义保持兼容。

同批交付同步 OpenAPI、课程 schema、生成类型、简版答案样例、后端接手文档、复盘接口说明和验证索引。接口仍为 41 操作、111 schema、11 类事件。
