# 新手使用说明

更新：2026-10-24。对应本次前端交付，第一关使用复盘验收预览，第二至四关继续正式验收；状态与边界见[版本索引](project-status.md)。

本平台在自己的电脑上学习使用 Agent，不要求编程基础。正式实训需要学生自行申请模型服务 API Key；API Key 相当于访问模型服务的凭证，通常对应自己的额度和费用。

## 安装与启动

首次安装需要联网。请先安装 Node.js 22 或以上、Python 3.11/3.12、uv，然后在项目根目录运行：

```powershell
uv sync --project apps/api --locked
npm --prefix apps/web ci
.\scripts\start.ps1
```

打开启动器显示的 `http://127.0.0.1:3000`。首次前端加载较慢时稍等刷新；启动器当前只检查后端健康。不要换成 localhost 或直接打开 8000 后端端口；本地来源和内部令牌由启动器匹配。端口占用时可以用 `-WebPort 3001 -ApiPort 8001` 指定空闲端口。启动失败时查看提示和 `data/runtime/` 中的日志，日志不应包含 Key。

停止应用：`scripts/stop.ps1`。自定义数据目录时，启动与停止传入相同 `-DataDir`。停止或重启会清空内存中的 Key；已有课程记录、提交与产物仍保存在数据目录中。

## 从第一关开始

首页的准备 Key 提示在至少一把 Key 已配置后隐藏，所有凭据缺失时恢复；这不代表连接检查已通过。

1. 在“探索课程”打开第一关，读完文字导读。无需 Key，不会调用模型。
2. 点“开始实训”，获得一个独立实验。开始本身不调用模型。之后可从课程列表或“学习记录”继续。
3. 在“模型设置”点击“添加 Key”，粘贴自己的 API Key。界面会按格式提供服务商建议；格式无法区分时选择一次服务商。DeepSeek、OpenAI 的地址自动填写，Key 只发送给所选服务商，不逐家尝试。
4. 点击“识别并获取模型”，从服务商返回的列表中选择模型。输入框立即清空；Key 只保存在本地后端内存，页面不能读回。兼容服务可以填写 API 根地址；接口不支持模型列表时，勾选“手动填写模型”，添加后仍需检查。
5. 勾选额度提示并点“检查连接”。最多三次模型请求，分别检查文本、工具调用及工具结果继续处理。模型出现在列表里并不代表这些能力已通过；检查通过后才能正式运行。
6. 返回实训，先用简单要求发起第一轮，再补充目标、限制、输出格式发起第二轮。在同一次实验中比较两次不同任务说明的结果。
7. 第一关在本地预览中以四步复盘作为验收界面；第二至四关核对事实、工具结果或产物后“提交验收”。逐条查看反馈与依据；不足可补充操作后重新提交。只有后端正式通过才显示课程完成。

第一关验收区已移除旧单选题和旧提交入口，采用复盘预览模板：选择两轮完整对话，引用新增要求和回答原文，判断要求是否满足，再用虚构通知区分已知和待确认信息。第二次没有改善也可如实分析。可下载 Markdown；草稿刷新或离开后清空，不上传、不计正式成绩、不在原有 ZIP 中。新的正式评分尚未接入，完成复盘不会自动通关；此前按原版本生成的成绩和反馈继续保留。

第二关的材料读取、日期和来源核对，第三关的真实查询与课程信息核对，以及第四关的审批、实际保存和产物校验都有可核查依据，继续保留正式验收。不能只通过页面上的选择或批准就替代后台执行证据。

请勿把 Key 粘贴到任务说明、系统指令、截图、聊天、问题报告或 GitHub。已提交的 Key 仍在内存时可在设置中主动清除。正在被任务使用的连接需要先等任务结束。

“我的 Key”支持添加多个 Key、切换、重命名和删除。切换模型后需重新检查；只重命名不影响已有检查结果。“清除当前 Key”保留名称和模型偏好；删除会移除该连接及其内存凭据，不影响其他 Key 或学习记录。重启后配置卡片仍在，但 Key 需要重新输入。

对于明确不提供模型列表的兼容服务，重新输入 Key 或刷新设置页时会保留当前手动模型，仍可主动检查连接；列表不支持不代表凭据提交失败。认证和网络等其他错误仍需按提示处理。

自动列表使用服务商提供的模型接口：[DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/)、[OpenAI 模型列表](https://developers.openai.com/api/reference/resources/models/methods/list)。获取列表本身不会自动发起实训对话。

选择 DeepSeek 时官方根地址为 `https://api.deepseek.com`；OpenAI 为 `https://api.openai.com/v1`，无需填写官网首页，也不填写 `/chat/completions`。其他兼容服务按其说明填写根地址，要求 `/v1` 时包含它。模型以下拉实时返回为准，不照抄旧截图里的测试模型名。

## 第二至四关

- 第二关：勾选“课程通知”，点“保存下一轮设置”。让 Agent 读取材料，再展开工具结果查看实际内容。选中文件只表示允许读取，不证明已经读过。根据原文填写日期与来源。
- 第三关：要求查询任务指定课程，打开工具输入和实际结果，填写课程日期与教室。Agent 的口头描述不能替代执行证据。
- 第四关：选择并保存材料设置。检查待办保存卡片的事项、日期、来源、位置和完整参数，先拒绝一次，再检查新的请求并批准。批准只记录决定；等显示“已保存 · 工具执行成功”后打开产物，对照材料核查并提交。

材料中的日期固定用于虚构教学，不是当前真实课程安排。现有课程内容仍按 1.0.0 版本归档；本轮修复使第四关实际按“先拒绝、后批准保存”验收，已冻结的旧成绩不重新计算。第四关目前对保存所需的任务 ID 指导不足，可能需要教师补充说明；已记录为待发布新课件版本解决的问题，不把已有后端测试视为零基础独立验收。

## 刷新、停止、重新开始与历史记录

刷新会从服务端重读实验、固定版本课程、消息和工具事件，再按序号恢复实时连接。它不会重发任务或重新保存文件。网络短暂断开会尝试续接事件；任务状态不明确时先刷新查看，不要连续发送相同操作。

点击发送后，任务说明立即出现在对话中；请求确认前会标注“正在发送”。模型返回文字分片后逐步显示，视野跟随最新输出。发送失败会恢复输入原文，并显示错误，不自动再次发送或调用模型。

“停止本轮”需要等实际终态才表示停止完成。停止不撤销服务商已经发生的调用费用，也不撤销已经完成的保存。重启后端时任务显示中断、未决批准失效；重新输入 Key 并检查后再主动发送新任务。

“重新开始”会先停止旧运行，成功后新建同课程版本、同模式的干净实验。旧实验变成只读记录，仍能查看和导出。“查看本关介绍”只回看导读，不重置进度。

旧实验的材料可以继续“预览原文”和下载，材料选择与设置保持只读。

每次提交冻结当时的证据与产物；“历史提交”能打开旧反馈和下载该次提交的文件快照。后续运行不会覆盖旧评分。运行结束后点“导出学习记录”，准备好后下载 ZIP，其中包含版本化课程、记录、提交和产物，不包含模型连接配置、Key 或内部令牌。

“学习记录”右侧显示开始日期（上海时区），实训页可点击标题旁的 ⓘ 查看日期、课程版本和模式；支持键盘展开和 Esc 关闭。绿色“已通关”表示该正式实训已获通过；红色“未通关”表示尚未正式通过。状态同时用图标和文字区分，演示检查通过也不会变成正式通关，旧记录仍保留原成绩。顶部“帮助”和“查看本关介绍”随时可用。

左侧“任务与设置”默认展开，包含任务、材料与 Agent 设置、产物和原文预览。点击侧栏顶部按钮可整体收起，为主任务让出空间；再点小图标即可恢复。每个板块也可单独折叠，收起不会丢失未保存的设置或输入。输入区有准备提醒时，点“前往设置”会自动展开设置；需要读取资料的关卡须先选择并保存材料，提醒会在准备完成后消失。材料“预览原文”会自动展开预览区并滚动定位，关闭后回到原按钮。

## 没有 Key 时试用

停止应用后，用 `scripts/start.ps1 -Demo` 启动。在导读页选择“先试试无 Key 演示”。演示根据预设流程执行，适合熟悉读取、批准、预览和提交；即使演示检查通过，也不会计入正式课程完成。返回导读后点“开始实训”创建正式实验，两种模式不能互相转换。

## 遇到错误

| 情况 | 处理 |
| --- | --- |
| Key 缺失 | 服务重启或已清除；重新输入并检查连接 |
| 认证失败 | 核对服务商、Key 有效性和可用额度，不在问题报告附 Key |
| 无法判断 Key 属于哪家 | 手动选择实际服务商；格式建议不能证明 Key 有效 |
| 接口不提供模型列表 | 对其他兼容服务使用“手动填写模型”，填准确模型 ID 后检查连接 |
| 模型列表为空或格式无效 | 核对服务商和根地址；不将官网首页当 API 地址，必要时询问服务商 |
| 文本通过、工具不通过 | 更换支持标准工具调用的模型；不同“兼容”服务不保证均可用 |
| 超时或模型不可用 | 检查网络、服务商状态，确认原任务状态后再主动重试 |
| 已有运行或配置被占用 | 等当前运行结束，或点停止并等待实际结束 |
| 设置版本冲突 | 其他页面已修改；刷新后重新操作 |
| 请求正在确认 | 不自动重复调用模型；先刷新检查是否已完成 |
| 批准过期或失效 | 旧批准不能复用，查看运行状态后重新发起任务 |
| 本地来源或令牌错误 | 从启动器显示的 127.0.0.1 地址打开，使用脚本一同重启前后端，无需登录 |

登录、班级管理、线上部署、任意代码执行和文件上传均不属于首版。页面调用 `/me` 保留身份扩展边界。
