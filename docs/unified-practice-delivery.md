# 统一实训与第一关正式复盘

实现日期：2026-10-25；状态更新：2026-10-26。PR #9 已合并到 main af36497，包含此前 PR #10 的复盘界面和正式后端。本文描述当前已合并功能。

## 使用流程

阅读导读 → 实践两轮 → 按需查看 Tips → 复盘或核对 → 提交验收 → 在弹窗中选择下一关/留在当前关卡。第一关 1.1.0 使用四步正式复盘，第二至四关保留实际读取、查询、拒绝/批准和产物检查。

第一关 1.0.0 保留原 choice 规则及成绩；新旧实验固定各自课程版本。旧实验可继续原版，也可从明确的新版本入口另开实验，不能暗中升级。课程目录列出最新版本；旧版完成不自动表示新版完成。

## 保存与评分

四步复盘先选自己的两轮，再引用新增要求、比较两次完整回答并做判断，最后完成版本化情境核对。两轮顺序依据服务端持久化创建顺序；引用包含 run/message/event 及原文 Unicode 码点偏移，重复句子和 emoji 可精确定位。

草稿自动保存到后端 SQLite，可刷新恢复；保存状态与正式提交区分。多页面编辑采用独立草稿 revision，冲突提示后由学生处理，不静默覆盖。保存失败时的浏览器后退/前进保留同一进程内的临时备份，返回显示恢复提示并暂停自动保存；不写浏览器持久存储。旧实验只读草稿保留；重置创建新实验，保留历史及当前 Key/模型。

正式提交冻结答案、规则结果与证据目录；历史可回看、引用可定位、ZIP 包含复盘草稿和正式答案。私有正确答案只在归档课程规则中，公开课件仅给题目。

正式通过检查真实两轮、真实改动引用、回答原文引用和变式判断。可以判断第二轮部分满足或没有满足；自由解释与下一条指令被收集保存，不以字数/关键词评分，通关表示完成基础操作与结构化核对，不宣称自由解释质量已自动验证。演示不计正式完成。

## Tips 与界面

主回答集中显示任务结果。默认收起的 Tips 展示差距和下一步建议，明确确认后单独调用当前已检查模型。按运行缓存，刷新/清 Key/重启后读取缓存不再次调用；失败手动重试。模型建议不改变正式成绩，不显示独立“依据”。当对应改进轮已有保存的复盘时，新生成 Tips 也可点评解释及引用；已缓存建议是生成时快照，后续编辑不会自动重评。沿用同一个主动确认的入口。

Markdown 表格容器内滚动。重置入口在顶部。提交结果使用弹窗，下一关先进入导读并保留模型选择；详细验收记录默认收起。

## 接口

v0.1.0 增量兼容：41 个 HTTP 操作、102 个 schema、11 类 SSE 事件。新增 ReflectionForm/ReflectionAnswers 和 GET/PUT /attempts/{attempt_id}/reflection-draft；正式提交复用 /submissions。草稿写请求携 expected_revision 和 expected_attempt_revision，无幂等键；丢失响应后先重读，不自动覆盖。完整协议见[契约](../contracts/README.md)。
