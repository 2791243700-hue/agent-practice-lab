# 第四关：管理权限并检查成果

### 本关学什么

学会在 Agent 执行操作前进行确认，并检查生成的文件是否满足任务要求。

### 先理解这些概念

“权限”规定 Agent 可以进行哪些操作。本关中，读取课程材料和保存待办文件具有不同的操作要求；保存前需要你批准。

“授权”是你对一次具体操作作出的决定。你应先检查准备保存的内容和位置，再选择批准或拒绝。拒绝表示这次保存不能执行；批准一次也不代表之后所有操作都获得许可。

“产物”是任务实际生成的结果，例如一份待办清单文件。Agent 回复“已完成”后，仍应打开文件检查内容。成功保存说明操作执行了，但清单是否完整、日期是否正确，还需要结合资料核验。

### 看一个小例子

Agent 准备保存一份待办清单，你发现其中漏了一项任务。可以先拒绝保存，让它补充，再检查新的保存请求。确认后批准，并打开生成的文件查看。

### 接下来做什么

检查 Agent 提出的待办清单保存请求，先练习拒绝并观察文件未发生变化，再要求重新保存、核对内容并批准。最后打开产物，与原始通知和查询结果对照后提交。

### 做到什么算完成

- 拒绝一次保存，确认该操作没有改变文件。
- 核对新的保存请求并批准，成功生成清单文件。
- 检查必要事项、日期和来源，提交产物并阅读反馈。


## 模型内容验收
