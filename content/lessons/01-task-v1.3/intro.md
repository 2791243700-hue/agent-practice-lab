# 第一关：让 Agent 理解任务

### 本关学什么

把希望 Agent 做的事说清楚，再检查它有没有照着要求做。目标是希望完成什么，约束是需要注意什么，输出要求是希望结果怎样呈现。

### 看一个小例子

第一轮可以说：“帮我整理本关课程通知。”看到回答后，第二轮补充：“请按截止日期从早到晚列成清单，未说明的信息标为待确认，不要猜测。”

“这段通知”默认指本关提供的课程通知，不需要重复粘贴；如果另外提供了通知，请明确指出要使用哪段材料。

### 接下来做什么

1. 阅读课程通知，用自己的话发起第一次尝试。
2. 根据回答补充一条目标、约束或输出要求，再试一次。
3. 系统自动带入最近两轮完整对话，你也可以更换轮次。
4. 选择第二轮回答是符合、部分符合还是不符合要求，再用一句话说明具体依据。
5. 确认模型验收的发送内容与费用，提交验收。

不用复制原文、填写引用位置或分类新增要求。回答仍有不足也没关系，准确指出问题同样可以通过。草稿自动保存，验收未通过时可按具体反馈修改。

### 选做：再试一个情境

可以展开另一段虚构活动通知，区分已知信息和待确认信息，再查看自查提示。未填写、未完成或答错都不影响第一关通关，选做内容不发送给正式验收模型。

### 验收检查什么

系统核对两轮真实对话，模型只检查“新增要求有效”和“判断有依据”。正式验收额外调用一次模型，失败不放行、不自动重试。Tips 为按需学习建议，不决定成绩。演示只用于熟悉操作，不计正式完成。
