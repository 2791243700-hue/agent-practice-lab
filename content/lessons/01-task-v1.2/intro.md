# 第一关：让 Agent 理解任务

### 本关学什么

学会说明目标、约束和输出要求，再用两轮真实对话和原文引用核对结果。最后通过一个小情境练习，区分已知信息与需要确认的信息。

### 先理解这些概念

Agent 是能够围绕任务使用模型和工具开展工作的助手。它可以整理资料、查询信息或生成文件，需要你说明目标，并检查结果。本关先练习任务表达，不使用工具。

你发给 Agent 的任务说明通常叫作“提示词”，用普通话语表达即可。目标是希望得到什么，约束是完成任务要遵守的要求，输出方式是你希望结果怎样呈现。未说明的信息需要确认，清楚的说明也不能保证回答完全正确。

### 看一个小例子

“帮我看看这段通知”没有说明需要怎样的结果。可以改为：“请提取需要办理的事项和截止日期，整理成清单；通知未说明的信息标记待确认，不要自行猜测。”

### 接下来做什么

1. 阅读本关提供的通知，先用自己的话发起一次任务。
2. 补充一条可以核对的目标、约束或输出要求，再运行一次。
3. 在四步复盘中选择自己的两轮，在第二轮原始指令里引用新增要求，并分别选择完整回答和其中的原文。
4. 判断要求已满足、部分满足或尚未满足，简短说明理由。后两种情况再写下一步指令。
5. 阅读另一段虚构活动通知，逐项判断哪些已说明、哪些需要确认，并写给 Agent 的要求。

草稿会自动保存，请留意保存状态；提交验收后可回看冻结答案与反馈。想听模型建议，可在草稿保存后主动生成改进轮的 Tips，可能额外消耗额度，已有建议不会自动更新。

### 做到什么算完成

- 选择同一实验中按顺序完成、各有完整回答的两轮运行。
- 引用真实新增要求，以及两轮完整消息中的原文和准确位置。
- 完成小情境的结构化信息核对。
- 填写自己的判断、理由和要求。系统先检查真实操作与引用，再调用模型核对新增要求、判断依据和改写是否合理。

第二轮没有改善也可以如实分析。演示只用于熟悉操作，正式模式的合格提交才计通关。旧版 1.0.0 实验保留原有选择题与成绩。


## 模型内容验收

正式提交前核对自己的回答与依据，并同意额外一次模型调用。所有客观证据及模型评分项均合格才通关；模型调用失败不会放行，也不会自动重试。模型逐项反馈供你修改，Tips 不代替正式评分。
