# 第三关：让 Agent 使用工具

### 本关学什么

认识工具调用，学会确认 Agent 是否真正获取了完成任务所需的信息。

### 先理解这些概念

“工具”是提供给 Agent 的一项具体能力，例如读取文件或查询课程安排。模型可以提出使用某个工具，由程序执行后把结果返回，Agent 再根据结果继续完成任务。

“工具输入”是执行时需要的信息，例如要查询哪门课程；“工具结果”是执行后得到的信息，例如课程日期与地点。工具调用可能成功，也可能因为输入不完整或服务异常而失败。

Agent 在回答里说“我已经查到了”，不等于查询确实发生。本关会让你查看实际调用记录，了解工具执行与最终回答之间的联系。

### 看一个小例子

整理课程待办时，如果需要确认某次课程的安排，可以让 Agent 使用课程查询工具，并根据返回日期调整清单。若查询失败，应先解决问题或说明信息缺失。

### 接下来做什么

本关已经提供课程安排查询工具。让 Agent 查询任务指定的信息，检查它传入了什么、得到了什么，再观察这些信息如何进入待办草稿。

### 做到什么算完成

- 完成指定的真实工具调用，并查看返回结果。
- 待办草稿正确使用了查询到的信息。
- 能区分任务说明、工具执行结果和 Agent 的最终回答。
